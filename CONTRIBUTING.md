# Contributing to Loom

This is a living companion repository, released under MIT, implementing OASIS Chapter 16 (Human–AI Workflow and Experience Engineering).

## What's Most Valuable

- **Filled-in blueprints from real workflows** — a real Human–AI Workflow Blueprint, sanitized of anything sensitive, is worth more than another abstract example.
- **Autonomy-ladder case studies** — a real account of promoting or demoting a workflow's autonomy mode, with the evidence that justified it.
- **Corrections to chapter mapping** — if a section here drifts from what [Chapter 16](https://github.com/knowledgetrailsai/OASIS/blob/main/methodology/chapter-16-human-ai-workflow-and-experience-engineering.md) or its companion documents actually say, flag it.

## How to Contribute

1. Fork the repository.
2. Changes to core structure (`01-foundations/`, `02-workflow-blueprint/`) — open an issue first.
3. Update `INDEX.md` if you add or rename a file.

## Code of Conduct

Be concrete. A blueprint entry should be specific enough that someone could build and operate the workflow from it — vague guidance adds noise, not value.
